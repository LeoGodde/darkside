# Darkside v1.1.0

## Nova skill: `/hunter` — Caçador de bug

O Darkside agora tem um investigador forense de bugs integrado ao ecossistema.

Em vez de chutar soluções e torcer para funcionar, o `/hunter` conduz uma investigação estruturada em 4 fases:

### Fase 1 — Rubber Duck
Perguntas direcionadas para forçar a articulação precisa do problema. O que deveria acontecer? O que está acontecendo? Desde quando? Com que frequência?

### Fase 2 — Escopo e Contexto
Investigação ativa de branches, commits recentes, ambiente do erro e perímetro de código afetado. O agente não só pergunta — ele investiga o git e o código junto com você.

### Fase 3 — Investigação Profunda
Baseada no modelo acadêmico de Andreas Zeller (*Why Programs Fail*): rastreia a cadeia causal **Defeito → Infecção → Falha** de trás pra frente até encontrar a causa raiz. Observação pura antes de qualquer alteração, hipótese única falsificável, e circuit breaker automático após 3 tentativas refutadas.

### Fase 4 — Plano de Correção
Gera especificação do fix e do teste de regressão, sem implementar. Ao final, pergunta se você quer executar a correção com `/order66`.
