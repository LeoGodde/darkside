# Darkside v1.2.0

## `/hunter` — Perguntas contextuais com opções A/B/C

O `/hunter` agora elabora perguntas **específicas ao bug reportado**, com opções A/B/C para guiar a investigação — o mesmo padrão interativo do `/mission`.

Antes, as perguntas eram fixas e genéricas ("O que deveria acontecer?", "Com que frequência?"). Agora o agente analisa o contexto do bug e gera opções relevantes para cada área:

- **Sintomas (Step 2):** 5 áreas (comportamento esperado, observado, timeline, frequência, impacto) com parágrafo contextual + opções A/B/C
- **Escopo (Step 3):** mudanças recentes, ambiente e perímetro de código com análise contextual + opções A/B/C

### Armazenamento renomeado

- Pasta: `.darkside/forensics/` → `.darkside/hunter/`
- Sufixo: `-forensics.md` → `-hunter.md`
